Your AI agents,
in the notch.

Visor turns the MacBook notch into a small control room for Claude Code, Copilot CLI, Antigravity and OpenCode. See what each agent is doing, answer it when it asks, and keep an eye on your limits without opening a single window.

brew install --cask tailamphat/tap/visor
Free and open source · macOS 14 or later · Apple Silicon and Intel · Setup steps · GitHub
The closed notch

Read it at a glance

With the notch closed, Visor shows a sliver of black on each side. That's enough room to tell you who is working and whether anyone needs you.

2

The left side shows each busy agent's mark with its session count, gently pulsing.

An amber "!" means an agent is waiting for your permission. Hover to open the card.

A blue "?" means an agent asked you something. Click its row to jump to that terminal.

What's inside

Four tabs and a card

Hover the notch to open it. Everything below is native Swift, with no web view.

Agents
Every running session, grouped by agent, with what it's doing right now ("Bash: npm test", "Edit: Main.swift"), which ones are waiting for you and which have finished.
Approvals
When Claude Code or Copilot CLI asks for permission, the notch opens with who is asking and Allow, Deny or Always allow, naming the rule (like git push).
Usage
Claude plan limits and API-value spend, Copilot premium requests on every account (company *.ghe.com too), Antigravity weekly limits, OpenCode Go limits and tokens.
Accounts
The gear on Usage lists each tool, whether it's connected and why not, with one button to fix it and a switch to hide it.
Clipboard
⌘⇧V from anywhere: search, pin and paste back into the app you were in. Passwords are never kept; history stays on this Mac.
Music
What Spotify, Apple Music or a browser tab is playing, with artwork, progress and play, pause and skip.

Privacy

Your data stays with you

Visor reads what's already on your Mac and talks only to the services your tools already use.

  • Your own sign-ins. Claude Code's keychain entry, gh, Copilot CLI and OpenCode, read when needed and never stored.
  • Each tool's own API. Usage comes from Anthropic, GitHub and OpenCode directly. Spend is worked out locally from Claude Code's logs.
  • Clipboard on this Mac. 200 items or 30 days, pins always. Copies your password manager marks as secret are skipped.
  • No account, no analytics. Visor has no server of its own.
Install

Up and running in a few minutes

Visor isn't from the App Store, so macOS asks you to approve it once. These are all the prompts you'll see, in order.

Install with Homebrew.

brew install --cask tailamphat/tap/visor

Already have it? Update with brew update && brew upgrade --cask visor. Homebrew only checks for new versions about once a day, so run brew update first.

Let macOS open it.

Homebrew clears the download flag for you, so Visor usually just opens. If macOS says Apple could not verify Visor, or that it's from an unidentified developer:

  1. Click Done (not Move to Trash).
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to "Visor was blocked to protect your Mac", click Open Anyway, enter your password, then click Open.

If macOS says Visor "is damaged", it still has the download flag. Remove it in Terminal, then open Visor again:

xattr -dr com.apple.quarantine /Applications/Visor.app

Connect your agents.

Hover the notch and choose Connect your agents (also in the menu bar icon). This adds Visor's hook to Claude Code, Copilot CLI and Antigravity so the notch hears what they do. Disconnect from the same menu before uninstalling.

Allow the permissions it asks for, when you first use them.

  • Accessibility: pasting from the clipboard history and the keyboard's media keys. In System Settings → Privacy & Security → Accessibility, turn on Visor.
  • Automation: play, pause and skip in Spotify, Music and your browser. Click Allow when macOS asks if Visor may control that app.
  • Keychain: reading the sign-in your AI tools already saved. If macOS asks whether security may use "Claude Code-credentials" or "copilot-cli", click Always Allow.

Hover the notch.

Usage fills in from the tools you're signed in to. If something is missing, the gear on the Usage tab says why and how to fix it.

Turned something down by mistake? Every permission can be changed later in System Settings → Privacy & Security. Uninstall with brew uninstall --cask visor.
